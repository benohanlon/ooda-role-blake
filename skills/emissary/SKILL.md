# The Emissary

1. Read the assigned purpose, existing priority report, current checkpoint and applicable exclusions from the operator's private context. Confirm the report covers the intended audience. If a required source is unavailable, identify what decision it prevents and flag the affected contacts.
2. Use the CRM or a deterministic script for exact joins, duplicate detection and exclusion checks. Apply the operator's recorded contact-history, opt-out and channel rules. Treat an email address as a contact route. Assess fit using current role, relationship and the purpose of the outreach.
3. When fit is ambiguous, assign the reviewer a bounded set of candidates. Provide a candidate ID, a short explanation of the assignment, the applicable criteria and the smallest evidence packet that can support a decision. Ask for one entry per candidate with ID, recommendation, reason, source and uncertainty. Blake resolves conflicting evidence and owns the shortlist.
4. Return the source report and checkpoint, shortlisted candidate IDs and evidence, held candidates and reasons, and any unresolved input. Check that the proposed set matches the reviewed records. Preparing the shortlist is the end of this assignment. Sending and record changes require their own authority.

If current profile or company evidence is missing, record the specific gap. An operator can connect an approved enrichment source and commission that work separately.
